## 🏆 Final Project: Local Agentic AI System

### What it does
A self-contained multi-agent assistant that runs entirely on your own hardware — no OpenAI, no cloud.

### Stack
| Component | Tool |
|-----------|------|
| LLM Backend | Ollama (Llama 3.2 / Mistral 7B) |
| Embeddings | `nomic-embed-text` via Ollama |
| Vector Store | ChromaDB (local) |
| Agent Framework | LangGraph or CrewAI |
| Tools | Web search (SearXNG), file reader, calculator |
| Memory | Persistent ChromaDB + Mem0 |
| UI | Open WebUI or Streamlit |
| Serving | Docker Compose |

### Architecture
```
User Input
    │
    ▼
┌─────────────────────┐
│   Orchestrator Agent │  ← Llama 3.2 via Ollama
└────────┬────────────┘
         │
    ┌────┴────┐
    │         │
    ▼         ▼
Researcher  Writer/Summarizer
 Agent       Agent
    │
    ▼
RAG Memory (ChromaDB + nomic-embed-text)
    │
    ▼
Tool Layer: [Web Search | File I/O | Calculator]
```

## 🛠️ Technologies

### Core
- **Python 3.11+** — primary language
- **LangChain / LangGraph** — chains, agents, RAG
- **CrewAI** — multi-agent orchestration
- **Ollama** — local LLM runtime (🦙 the star of the show)

### Models (local via Ollama)
- `llama3.2` — general purpose
- `mistral` — fast, instruction-tuned
- `phi3.5` — lightweight, Microsoft
